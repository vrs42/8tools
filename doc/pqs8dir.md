**pqs8dir** prints the directories of a P?S/8 volume.

Given the name of a P?S/8 volume on the command line,
the file is opened and checked for P?S/8 content.  If
found, the P?S/8 version number will be reported, and 
the system DIRECTory and the CATalog will be printed.

Different formats of the DIRECTory listing are possible,
depending on which version of P?S/8 was found.
