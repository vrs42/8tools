**bnhtm2od** converts a text .BN file to -pb.od format.

This tool provides quick conversion of .BN files from media
images on the Internet to a useable form.

Given a list of files to process, each file has the .htm
extension, if any removed, and -pb.od added to form the
name of a corresponding output file.

The input is converted from the popular online octal dump
format into BIN format, which is then dumped in a format
suitable for the mktapes utility.

Existing files will not be over-written.
