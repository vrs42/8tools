4to3 packs files 2 words every 3 bytes

This takes a list of input files on the command line.
These files are presumed to be storing 3 characters
for every pair of words, in the manner of OS/8.  Each
word is presumed to be stored as two bytes, as in a 
.dsk file.

For each such file, a .od file is written containing
an octal representation of each byte, one per line.
These output files are suitable for processing by the 
mktapes utility.

Pre-existing output files will be skipped, with a 
warning message.
